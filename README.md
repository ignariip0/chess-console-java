# chess-console-java

Jogo de xadrez para terminal em Java puro, desenvolvido para praticar
orientação a objetos: herança, polimorfismo, classes abstratas e exceções personalizadas.

🚧 Em desenvolvimento

## Estrutura
- `boardgame` → tabuleiro genérico (Board, Piece, Position)
- `chess` → regras do xadrez (ChessMatch, ChessPiece)
- `application` → interface de console
